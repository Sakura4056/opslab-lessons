# OpsLab 运维学习闯关

> 零基础 → 初级运维工程师的原创闯关式课程：36 讲 + 6 份阶段测试卷，覆盖 Linux / 网络 / Shell / Nginx·MySQL·Redis / Docker·K8s / 求职冲刺。

## 使用

- 打开本页即可开始：左侧「关卡地图」按顺序解锁关卡，每讲附 3 题闯关测验；
- 每讲含：学习目标 / 核心概念 / 命令实操 / 动手实验 / 常见坑 / 自测；
- 进度保存在浏览器 localStorage；右上「自由模式」可跳过解锁。
