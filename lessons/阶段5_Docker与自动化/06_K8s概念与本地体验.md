# K8s 概念与本地体验

> 阶段笔记：[[阶段5_Docker与自动化]] ｜ 上一讲：[[阶段5_Docker与自动化/05_监控与CI_CD概念|监控与CI/CD概念]] ｜ 下一讲：[[阶段6_求职冲刺/01_面试八股速览|面试八股速览]]
> 2026 岗位硬要求「会 K8s」——本地用 **Docker Desktop 自带的 Kubernetes** 就能完成全部实操，无需云端。

## 学习目标

- 讲清 Pod / Deployment / Service 三个核心对象的关系
- 启用 Docker Desktop 内置 K8s，用 kubectl 部署并暴露一个应用
- 掌握 kubectl 高频命令 10 条，理解「声明式」与自愈

## 核心概念

```
Pod        最小调度单元（1 个或多个容器的组合）
Deployment 管理 Pod 副本的控制器：声明"要 3 个副本"，挂了自动重建
Service    一组 Pod 的稳定访问入口（ClusterIP 集群内 / NodePort 节点暴露）
```

**声明式 vs 命令式**：Docker 是「跑这个命令」；K8s 是「我要这个最终状态」——控制器持续比对现状与声明并自动修正（自愈、滚动更新、扩缩容的来源）。

## 命令实操

### 1. 启用本地集群

Docker Desktop → Settings → Kubernetes → **Enable Kubernetes** → Apply（等待几分钟）。验证：

```bash
kubectl get nodes             # docker-desktop 节点 Ready
kubectl version --short
kubectl config current-context   # docker-desktop
```

### 2. 部署一个应用（声明式三步）

```bash
kubectl create deployment web --image=nginx:1.27-alpine --replicas=2
kubectl get pods -o wide              # 两个 Pod，各自有 IP
kubectl expose deployment web --port=80 --type=NodePort
kubectl get svc web                   # 拿到 NodePort 端口（3xxxx）
curl http://localhost:<NodePort>/     # NodePort 端口本机即可访问
```

### 3. 体验「自愈」与「扩缩容」（K8s 的灵魂）

```bash
kubectl delete pod <某个pod名>        # 手动杀一个 → 自动重建新的（Replicas 保持 2）
kubectl scale deployment web --replicas=5
kubectl get pods -w                   # -w 实时观察滚动
kubectl rollout restart deployment web
kubectl rollout undo deployment web   # 回滚（需先有变更历史）
```

### 4. 用 YAML（声明式的正式形态）

```yaml
# deploy.yaml
apiVersion: apps/v1
kind: Deployment
metadata: { name: web }
spec:
  replicas: 2
  selector: { matchLabels: { app: web } }
  template:
    metadata: { labels: { app: web } }
    spec:
      containers:
        - name: nginx
          image: nginx:1.27-alpine
          ports: [{ containerPort: 80 }]
```

```bash
kubectl apply -f deploy.yaml          # apply = 声明式标准动作
```

## 常见坑

- **镜像拉取失败 ImagePullBackOff**：本地构建的镜像 K8s 不认（要在 Docker Desktop 的镜像仓库内，即本机构建即可）；
- **NodePort 范围**：30000~32767，写 80 会报错；
- **别把 K8s 当 Compose 用**：K8s 不用 `-p` 端口映射思路，用 Service 抽象；
- **kubectl 命令记不全**：`kubectl cheat sheet`（官方）+ `kubectl explain pod.spec` 内置文档。
