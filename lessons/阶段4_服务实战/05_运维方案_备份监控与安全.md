# 运维方案：备份、监控与安全

> 阶段笔记：[[阶段4_服务实战]] ｜ 上一讲：[[阶段4_服务实战/04_LNMP串联实战|LNMP串联实战]] ｜ 下一阶段：[[阶段5_Docker与自动化/01_Docker核心概念与命令|Docker核心概念与命令]]
> 项目①的收尾：服务能跑只是及格，**有备份、有监控、有安全基线**才算完整方案。

## 学习目标

- 为 LNMP 环境落地「数据库备份 + 配置备份」的定时任务
- 建立基础资源监控（无需 Prometheus，先会用系统自带 + 简单脚本）
- 完成安全基线：防火墙、SSH 加固、最小暴露面

## 核心概念

### 安全基线四件事（服务器裸奔 = 事故预定）

```
① 防火墙：只开必要端口（ufw）
② SSH：禁 root 密码登录、改端口、用密钥
③ 更新：apt 定期 upgrade + unattended-upgrades 自动安全更新
④ 暴露面：服务只监听必要地址；数据库绝不绑 0.0.0.0 对公网
```

## 命令实操

### 1. 备份方案（复用阶段 3 技能）

```bash
# 数据库每日备份：sudo crontab -e
30 2 * * * mysqldump -uroot -p'密码' --single-transaction appdb \
  | gzip > /var/backups/mysql/appdb_$(date +\%F).sql.gz
# 注意 crontab 里 % 要转义为 \%

# 配置备份：/etc/nginx /etc/systemd/system /opt/app
0 3 * * * tar -czf /var/backups/conf/conf_$(date +\%F).tar.gz /etc/nginx /etc/systemd/system
```

### 2. 基础监控（无监控组件时的土办法）

```bash
# 磁盘告警脚本（>85% 输出告警行），挂 cron 每 10 分钟
df -h | awk '$5+0 > 85 {print "DISK WARN:", $6, $5}'

# 服务存活巡检：挂 cron 每 5 分钟，挂了自动拉起
systemctl is-active --quiet flaskapp || sudo systemctl restart flaskapp

# 进阶预告：真正的监控体系 = Prometheus(采集) + Grafana(看板) + Alertmanager(告警)
#            日志集中 = ELK/EFK —— 阶段 5 讲概念，入职后深入
```

### 3. 防火墙与 SSH 加固

```bash
sudo apt install -y ufw
sudo ufw allow 22/tcp          # 先放行 SSH 再 enable，防自锁！
sudo ufw allow 80,443/tcp
sudo ufw enable && sudo ufw status verbose

# SSH 加固（/etc/ssh/sshd_config）：
#   PermitRootLogin no           禁 root 直接登录
#   PasswordAuthentication no    仅密钥登录（先确保密钥能连！）
#   Port 2222                    可选：改端口减少扫描噪音
sudo systemctl restart ssh
```

## 常见坑

- **ufw enable 前没放行 22**：云主机直接把自己锁外面（有控制台还能救）；
- **sshd 改配置先开新连接测试**：旧会话别断，确认新配置能连再关旧会话；
- **备份存本机**：服务器挂 = 备份也没了，至少再传一份到对象存储/其他机器；
- **监控告警无人看**：告警要有人响应才有意义，宁可少而准。
