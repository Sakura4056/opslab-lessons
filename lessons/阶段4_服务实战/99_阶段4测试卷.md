# 阶段 4 测试卷：服务实战

> 时量建议 75 分钟。实操部分**在你的 LNMP 环境真实执行**并留证据（命令输出）。

## 一、简答（每题 5 分，共 40 分）

1. `nginx -t`、`systemctl reload`、`restart` 三者的动作差异？改完配置的标准动作序列？
2. 403 Forbidden 在 nginx 场景的两个常见原因与排查命令？
3. MySQL 建应用账号的最小权限原则怎么落地？写出给 `app` 授权 appdb CRUD 的 SQL。
4. `mysqldump --single-transaction` 解决什么问题？
5. RDB 与 AOF 的取舍？生产环境推荐组合？
6. Redis 的 maxmemory 满了之后有哪些淘汰策略？纯缓存场景选哪个？
7. gunicorn 相比 Flask 内置服务器的意义？`-w 2` 是什么？
8. 服务器安全基线四件事？

## 二、实操（每题 10 分，共 40 分）

9. 新建静态站点 `demo.local`：自签证书上 HTTPS + 80 强制 301 跳转 + `curl` 三连验证（http 301 / https 200 / 错误域名 404）。
10. 建库 `testdb`、用户 `tester`@localhost 仅 SELECT 权限；验证 tester 不能 CREATE；然后删除该用户。
11. mysqldump 备份 testdb → 删库 → 恢复 → 查询验证数据完整（全过程记录命令）。
12. 停掉 Redis，`curl /api/visit` 观察现象与 error.log，恢复 Redis，服务自愈验证。

## 三、场景（每题 10 分，共 20 分）

13. 周日早上收到告警：网站 503。写出你的完整排查与处置流程（含对外沟通话术要点）。
14. 备份任务连续三天失败，日志显示 `mysqldump: Got error: 1045`——分析原因并给出修复与防复发方案。

## 参考答案要点

**1.** -t 只验语法；reload 平滑加载；restart 中断重起。序列：改配置 → nginx -t → reload。（第 01 讲）
**2.** 目录权限（worker 无 x/r）与 index 缺失；`ls -l /var/www`、`nginx -T` 查看，error.log 有 denied 记录。（第 01 讲）
**3.** `CREATE USER 'app'@'10.0.0.%' IDENTIFIED BY '强密码'; GRANT SELECT,INSERT,UPDATE,DELETE ON appdb.* TO 'app'@'10.0.0.%';`（第 02 讲）
**4.** InnoDB 一致性快照备份，避免锁表影响业务。（第 02 讲）
**5.** RDB 快照恢复快但丢数据窗口大；AOF 追加丢得少但文件大恢复慢；生产两者同开。（第 03 讲）
**6.** noeviction/allkeys-lru/volatile-lru 等；纯缓存选 allkeys-lru。（第 03 讲）
**7.** 生产 WSGI 服务器，多 worker 并发与进程管理；-w 2 = 2 个 worker 进程。（第 04 讲）
**8.** 防火墙最小暴露 / SSH 加固 / 定期更新 / 服务监听收敛。（第 05 讲）
**9.** 要点：openssl 自签 -CN=demo.local；server 80 返回 301；server 443 ssl 三行配置；`curl -sI http://...` 看 301、`curl -k https://...` 看 200、换域名看 404。（第 06 讲）
**10.** 建库建用户仅 SELECT → `CREATE` 测试报错 → `DROP USER tester@localhost`。（第 02 讲）
**11.** dump → `DROP DATABASE` → `CREATE` → `mysql testdb < dump.sql` → `SELECT COUNT(*)` 对比。（第 02 讲）
**12.** 500/502 出现、error.log 出现 connect refused；`systemctl start redis-server` 后恢复——体验依赖故障。（第 04 讲）
**13.** 止血（确认范围→回滚/重启/扩容）→ 分层定位（503 来源：nginx 返回还是后端）→ 保留日志现场 → 对外沟通（已知原因/预计恢复/影响范围）→ 复盘补监控。（第 05 讲+阶段 2）
**14.** 1045=认证失败：cron 环境变量/密码文件权限不对（.my.cnf 600）、或密码被轮换未同步；修复：`~/.my.cnf` 固化凭证 chmod 600；防复发：备份任务加退出码告警。（第 05 讲+阶段 3 cron 坑）
