## Linux 系统类

| 问题 | 答案要点（30 秒版） |
|---|---|
| 服务器负载高怎么查？ | `uptime` 看负载 → `top` 找进程（P/M 排序）→ 进程级定位：CPU 高看代码/死循环，IO 高用 `iostat`/`iotop` |
| 查看端口占用 | `ss -tlnp` / `lsof -i:80`；杀进程 `kill PID`（先 15 后 9） |
| 软链接 vs 硬链接 | 硬链接同 inode 多名字，不能跨文件系统不能指目录；软链接是路径快捷方式，原文件删则失效 |
| 755 是什么权限 | 所有者 rwx，组和其他 r-x；目录 755 + 文件 644 是常见基线 |
| inode 是什么 | 文件元数据+数据指针；`df -i` 看用量；小文件海把 inode 耗尽写入失败 |
| 静态库/动态库、PATH 失效 | 简述即可；PATH 覆盖导致命令全失灵是经典事故题 |

## 网络类

| 问题 | 答案要点 |
|---|---|
| 三次握手四次挥手 | SYN → SYN+ACK → ACK；FIN → ACK → FIN → ACK；TIME_WAIT 2MSL 防旧包，主动关闭方停留 |
| OSI/TCP-IP 模型 | 物理链路网络传输应用（TCP-IP 四层）；每层一个代表设备/协议 |
| DNS 解析过程 | hosts → 本地 DNS → 根 → 顶级域 → 权威；递归+迭代 |
| 502 vs 504 | 502=后端返回无效（挂了）；504=后端超时没回——都查 upstream 与日志 |
| HTTP 与 HTTPS | HTTPS=TLS 握手（证书/密钥协商）+对称加密；证书校验：域名/有效期/CA 链 |

## 数据库与中间件

| 问题 | 答案要点 |
|---|---|
| MySQL 备份方式 | mysqldump 逻辑备份（--single-transaction）vs 物理备份；备份必须可恢复演练 |
| 慢查询优化思路 | 开 slow log → EXPLAIN 看执行计划（索引/type/rows）→ 加索引/改写 SQL |
| Redis 持久化 | RDB 快照恢复快丢数据多；AOF 追加命令丢数据少；生产两者并用 |
| Redis 缓存三问题 | 穿透（查不存在的 key：布隆/空值缓存）、击穿（热 key 过期：互斥重建）、雪崩（批量同过期：随机 TTL） |
| MySQL 主从原理 | binlog → 从库 IO 线程拉取 → relay log → SQL 线程重放 |

## Docker 与自动化

| 问题 | 答案要点 |
|---|---|
| 镜像和容器 | 镜像只读分层模板；容器=镜像运行实例（进程级隔离）；数据持久用 volume |
| Dockerfile 优化 | 分层缓存（依赖先拷代码后拷）、多阶段构建、固定版本、非 root、slim 基础镜像 |
| Compose/K8s 区别 | Compose 单机编排；K8s 跨节点调度/自愈/扩缩容（Deployment/Service/Pod 三概念能讲清） |
| Ansible 幂等 | 描述期望状态，模块自动判断差异；跑 N 遍结果一致 |
| CI/CD 流程 | push → 构建测试 → 镜像 → 部署（审批）；工具 GitHub Actions/Jenkins |
