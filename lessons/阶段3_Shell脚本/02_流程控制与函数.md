# 流程控制与函数

> 阶段笔记：[[阶段3_Shell脚本]] ｜ 上一讲：[[阶段3_Shell脚本/01_Shell基础语法|Shell基础语法]] ｜ 下一讲：[[阶段3_Shell脚本/03_cron定时任务|cron定时任务]]

## 学习目标

- 熟练 if/case/for/while 四种结构
- 会写带参数、带返回值的函数并复用
- 掌握条件判断文件/字符串的 `-f -d -z -n` 系列用法

## 核心概念

```bash
if [ -f /etc/passwd ]; then    # [] 两侧必须有空格！
  echo "存在"
elif [ -d /tmp ]; then
  echo "..."
else
  echo "都不满足"
fi

case $1 in                     # 多分支（比 elif 链清晰）
  start) echo "启动" ;;
  stop)  echo "停止" ;;
  *)     echo "用法: $0 {start|stop}"; exit 1 ;;
esac

for f in /var/log/*.log; do    # 遍历通配结果
  echo "处理 $f"
done

for i in 1 2 3; do echo $i; done
while read line; do echo "$line"; done < input.txt    # 逐行读
```

### 判断符速查

| 表达式 | 真 当 |
|---|---|
| -f / -d / -e | 存在文件 / 存在目录 / 存在 |
| -z / -n | 字符串为空 / 非空 |
| "$a" = "$b" | 字符串相等（比较用 =，且要加引号） |
| -eq -ne -lt -gt | 数字 相等/不等/小于/大于（数字别用 = <） |

### 函数

```bash
log() {                        # 定义：函数名() { ... }
  echo "[$(date '+%F %T')] $*"   # $* = 全部入参
}

check_port() {                 # 带返回值：0 成功 1 失败
  nc -zv "$1" "$2" >/dev/null 2>&1
  return $?
}

log "开始检查"
if check_port 127.0.0.1 22; then
  log "22 端口开放"
else
  log "22 端口关闭"; exit 1
fi
```

**实战惯例**：脚本开头定义 `log()` 与 `die()` 两个函数，全篇用它输出——日志有统一时间戳，失败有统一出口。

## 常见坑

- **[] 内没空格**：`[$a = $b]` 报错；`[ "$a" = "$b" ]` 才对；
- **数字用 = 比较**：`[ "$a" = 5 ]` 是字符串比较，数字用 `-eq` 或 `(( a == 5 ))`；
- **for 遍历空格文件名**：`for f in $(ls)` 会拆词——用 `for f in /path/*` 或 `while read`；
- **函数里 exit**：直接退出整个脚本；只想中断函数用 `return`。
