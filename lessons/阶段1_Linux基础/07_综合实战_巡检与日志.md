## 实战一：系统巡检脚本

```bash
mkdir -p ~/lab && vim ~/lab/sys_check.sh
```

```bash
#!/bin/bash
# sys_check.sh — 主机巡检报告
# 用途：输出 CPU/内存/磁盘/负载/登录 用户 概览；依赖：coreutils
echo "===== 系统信息 ====="
hostname; cat /etc/os-release | grep PRETTY
uptime                                    # 负载 + 运行时长
echo "===== CPU TOP3 ====="
ps aux --sort=-%cpu | head -4 | awk '{print $3"%  "$11}'
echo "===== 内存 ====="
free -h
echo "===== 磁盘（>80% 告警） ====="
df -h | awk '$5+0 > 80 {print "⚠ 告警:", $6, $5}'
df -h | awk 'NR==1 || $5+0 <= 80'
echo "===== 登录用户 ====="
who
```

```bash
chmod +x ~/lab/sys_check.sh && ~/lab/sys_check.sh
# 验证无误后按规范入库：
cp ~/lab/sys_check.sh /mnt/d/OpsLab/03_Scripts/shell/
```

## 实战二：日志切割清理脚本

```bash
#!/bin/bash
# log_rotate.sh — 按日期切割并清理旧日志
# 用法：./log_rotate.sh <日志文件> <保留天数>
LOG=$1; KEEP=${2:-30}
[ -z "$LOG" ] && { echo "用法: $0 <日志文件> [保留天数]"; exit 1; }
[ -f "$LOG" ] || { echo "日志不存在: $LOG"; exit 1; }

DATE=$(date +%Y%m%d)
cp "$LOG" "${LOG}.${DATE}" && : > "$LOG"        # 切割：复制后清空原文件
gzip "${LOG}.${DATE}"                            # 压缩存档
find "$(dirname "$LOG")" -name "$(basename "$LOG").*" -mtime +$KEEP -delete
echo "[$(date '+%F %T')] 已切割 $LOG，保留 $KEEP 天"
```

```bash
chmod +x log_rotate.sh
./log_rotate.sh /var/log/syslog-test 7     # 用测试文件演练
```

## 常见坑

- **脚本没执行权限**：Permission denied → chmod +x；
- **Windows 换行符**：在 Windows 编辑的脚本报 `/bin/bash^M: bad interpreter` → `sed -i 's/\r//' script.sh`；
- **清空大日志**：`: > file`（保留 inode）优于 `rm` 后重建（服务还握着旧句柄）；
- **巡检脚本输出太长**：生产版要控制信息密度，告警优先。
