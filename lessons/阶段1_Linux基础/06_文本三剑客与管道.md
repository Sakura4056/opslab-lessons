# 文本三剑客与管道

> 阶段笔记：[[阶段1_Linux基础]] ｜ 上一讲：[[阶段1_Linux基础/05_进程与服务systemd|进程与服务systemd]] ｜ 下一讲：[[阶段1_Linux基础/07_综合实战_巡检与日志|综合实战]]
> **运维面试必考 + 日常最高频**：日志分析全靠这三样。

## 学习目标

- 理解管道 `|` 与重定向 `>` `>>` `2>` 的数据流
- grep 精确过滤、sed 批量替换、awk 按列统计
- 能独立完成一条「日志分析」组合命令

## 核心概念

```
命令1 | 命令2 | 命令3      # 管道：前者的 stdout 接到后者的 stdin
cmd > file                 # 覆盖写入
cmd >> file                # 追加写入
cmd > out.log 2> err.log   # 分别收 stdout(1) 和 stderr(2)
cmd > /dev/null 2>&1       # 丢弃一切输出（定时任务常用）
```

| 剑客 | 定位 | 记忆 |
|---|---|---|
| grep | **找**（行级过滤） | grep = global regex print |
| sed | **改**（流编辑：替换/删除/插入） | sed = stream editor |
| awk | **统计**（按列取数/计算/汇总） | awk 按空格默认分列 $1$2$3 |

## 命令实操

### grep 精确过滤

```bash
grep -c "GET" access.log            # 只数出现次数
grep -n "error" app.log             # 带行号
grep -E "error|fail" app.log        # 扩展正则：多关键词
grep -A 3 "Exception" app.log       # 匹配行 + 后 3 行（-B 前 -C 前后）
grep -oE "[0-9]{1,3}(\.[0-9]{1,3}){3}" access.log   # -o 只输出匹配到的 IP
```

### sed 批量替换

```bash
sed 's/old/new/' file.txt           # 每行第一个 old → new
sed 's/old/new/g' file.txt          # g 全局替换
sed -i 's/8080/9090/g' app.conf     # -i 直接改文件（改前备份：-i.bak）
sed -n '5,10p' file.txt             # 只打印 5~10 行（-n 抑制默认输出）
sed '/^#/d' nginx.conf              # 删除注释行
```

### awk 按列统计

```bash
awk '{print $1}' access.log                 # 取第 1 列（默认空格分列）
awk '{print $NF}' access.log                # 最后一列
awk -F: '{print $1}' /etc/passwd            # -F 指定分隔符（取用户名）
awk '{s+=$10} END {print s}' access.log     # 累加第 10 列（流量）
awk '{a[$1]++} END {for(k in a) print a[k], k}' access.log | sort -rn | head
                                            # ⭐ 统计每个 IP 出现次数并倒序 Top
```

### 组合拳（背下来）

```bash
# 访问 Top10 IP
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -10
# 今天错误日志的最后 20 条
grep "ERROR" app.log | grep "$(date +%Y-%m-%d)" | tail -20
# 找出占用内存最高的 3 个进程
ps aux --sort=-%mem | head -4
```

- [ ] `ls -l | grep "^d"` 只列出目录；`ls -l | awk '{print $5, $9}'` 只看大小和名字

## 常见坑

- **sed -i 直接改生产配置**：永远 `-i.bak` 留备份；
- **awk 默认分隔符是连续空白**，CSV 要 `-F','`；
- **grep 正则里 `.` 会匹配任意字符**：搜 IP/版本号要转义 `\.` 或用 `-E` 加引号；
- **`>` 覆盖了重要文件**：重定向方向看清楚，重要日志用 `>>`。
