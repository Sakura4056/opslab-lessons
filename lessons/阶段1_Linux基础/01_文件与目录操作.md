## 学习目标

- 熟练使用 12 个最常用的文件/目录命令
- 会用 find 按条件找文件、会看文件类型与大小

## 核心概念

**目录树**：Windows 有 C 盘 D 盘，Linux 只有**一棵树**，根是 `/`。Windows 的 D 盘在 WSL 里是 `/mnt/d`。

| 目录 | 放什么 | 运维关注点 |
|---|---|---|
| /etc | 配置文件 | nginx、ssh、systemd 配置都在这 |
| /var | 经常变化的数据 | **日志 /var/log**、网站根 /var/www |
| /home | 普通用户家目录 | 个人文件 |
| /root | root 的家目录 | |
| /tmp | 临时文件，重启可能清空 | 别放重要东西 |
| /usr, /opt | 安装的软件 | 自装软件常放 /opt |

**路径**：绝对路径从 `/` 写起（`/etc/nginx/nginx.conf`）；相对路径从当前位置写起（`.` 当前目录、`..` 上一级、`~` 家目录）。

## 命令实操

```bash
pwd                  # 我在哪（打印当前目录）
ls -lh               # 长格式+人类可读大小；-a 看隐藏文件（.开头）
cd /var/log          # 切目录；cd .. 上一级；cd ~ 回家；cd - 回上个目录

mkdir -p demo/a/b    # -p 一次建多级目录
cp demo/a/b/x.txt demo/a/        # 复制；-r 复制目录
mv old.txt new.txt   # 改名；mv f.txt /tmp/ 移动
rm demo/a/b/x.txt    # 删除文件；-r 删目录；-f 不询问
                     # ⚠️ rm -rf 只对明确的路径使用，删前先 pwd 确认

touch a.txt          # 创建空文件/更新时间戳
file a.txt           # 看文件类型（文本?二进制?）
du -sh /var/log      # 目录总大小；-s 汇总 -h 人类可读
df -h                # 各挂载点磁盘使用率（运维每天看）

# find：按名字/大小/时间找文件（运维高频）
find /var/log -name "*.log"            # 按名字
find / -size +100M -type f 2>/dev/null # 大于100M的文件，忽略报错
find /etc -mtime -7 -name "*.conf"     # 7天内改过的配置
find /var/log -name "*.log" -mtime +30 # 30天前的旧日志（配合删除脚本）
```

**通配符**：`*.log`（任意字符）、`data?.txt`（单个字符）、`[abc]*`（ab c 开头）。

## 动手实验

- [ ] 在家目录建 `lab/{conf,logs,data}` 三级结构，并 `tree lab` 查看（没有 tree 就 `find lab`）
- [ ] 复制 `/var/log` 下任一 `.log` 到 `lab/logs/`，重命名为 `sys.log`
- [ ] 用 find 找出 `/etc` 下 7 天内修改过的 `.conf`，记录数量
- [ ] 用 du 找出 `/var/log` 里最大的一个日志文件
- [ ] 把整个 lab 目录删掉，删之前先 `pwd` + `ls` 确认位置

## 常见坑

- **rm -rf 误删**：变量为空时 `rm -rf $DIR/*` 变成 `rm -rf /*`。永远先 echo 出路径再删；
- **大小写敏感**：`Readme.txt` 和 `readme.txt` 是两个文件（Windows 不敏感）；
- **cp 不带 -r 复制目录**：报 `omitting directory`；
- **文件名带空格**：要加引号 `cp "my file.txt" /tmp/`。
