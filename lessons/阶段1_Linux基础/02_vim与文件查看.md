# vim 与文件查看

> 阶段笔记：[[阶段1_Linux基础]] ｜ 上一讲：[[阶段1_Linux基础/01_文件与目录操作|文件与目录操作]] ｜ 下一讲：[[阶段1_Linux基础/03_用户权限与文件系统|用户权限与文件系统]]
> 运维现实：服务器上没有 VS Code，**vim 是唯一 guaranteed 的编辑器**；看日志是日常。

## 学习目标

- 掌握 vim 三种模式与保命操作（打开、改、存、退）
- 熟练用 cat/less/head/tail/wc 查看文件，尤其**实时日志**
- 会用 grep 在文件里精确找到目标行

## 核心概念：vim 三种模式

```
        i / a / o          Esc
普通模式 ────────→ 插入模式 ────────→ 普通模式
    ↑                                      │
    │  :w 保存   :q 退出   :wq 保存退出    │ : 进入命令行模式
    └────────────── 底线命令模式 ←─────────┘
```

- **普通模式**（打开默认）：移动光标、删除、复制粘贴；
- **插入模式**：真正打字（`i` 光标前插入、`a` 后插入、`o` 新起一行）；
- **底线命令模式**：`:` 开头，保存/退出/查找替换。

## 命令实操

### vim 保命八连（先会这些再谈其他）

```vim
vim /etc/hosts      # 打开文件
# 普通模式：gg 到第一行，G 到最后一行，5G 到第 5 行
# dd 删除当前行，5dd 删 5 行；yy 复制当前行，p 粘贴
# u 撤销，Ctrl+r 重做
/string             # 向下搜索 string，n 下一个，N 上一个
:wq                 # 保存退出；:q! 不保存强制退出
:set number         # 显示行号（写入 ~/.vimrc 永久生效）
```

### 文件查看五件套

```bash
cat /etc/hosts              # 小文件一次全看；-n 带行号
less +F /var/log/syslog     # 大文件分页看：空格翻页，/关键词搜索，q 退出
head -20 nginx.conf         # 看头 20 行
tail -f /var/log/nginx/access.log   # ⭐ 实时追踪日志（运维日常）
tail -100 error.log         # 看最后 100 行
wc -l access.log            # 行数统计（-l 行 -w 词 -c 字节）
grep -i "error" app.log     # 搜关键词；-i 忽略大小写
grep -rn "listen" /etc/nginx/       # -r 递归目录 -n 显示行号
grep -v "^#" nginx.conf     # -v 反选：排除注释行（看有效配置）
```

## 动手实验

- [ ] `tail -f /var/log/syslog` 观察 30 秒，Ctrl+C 退出

## 常见坑

- **vim 卡死像死机**：按了 `Ctrl+s`（终端冻结），按 `Ctrl+q` 解冻；
- **误进插入模式疯狂输入**：先 Esc 回普通模式再操作；
- **tail -f 大文件翻页**：`tail -f` 无法翻页，需要交互时用 `less +F`（Ctrl+C 停止追踪后可自由翻页）；
- **grep 中文/正则**：`grep "a.b"` 里 `.` 是任意字符，想搜字面点号要 `grep "a\.b"`。
